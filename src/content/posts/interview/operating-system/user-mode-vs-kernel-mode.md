**用户态和内核态是 CPU 的两种不同运行级别（特权级）**。操作系统通过这种方式来保护系统安全，防止应用程序随意破坏硬件或内核数据。

- **用户态**：应用程序运行的状态。**权限受限**，不能直接访问硬件，不能执行特权指令。
- **内核态**：操作系统内核运行的状态。**权限最高**，可以执行所有 CPU 指令，直接访问内存、硬盘、网卡等所有硬件资源。
