HashMap 默认初始容量为 `16`，负载因子为 `0.75`。当元素数量达到阈值后，会创建一个容量翻倍的新数组，并将旧数组中的节点迁移过去。

## JDK 8 的迁移优化

容量翻倍后，节点无需重新做完整的取模计算。根据节点 hash 与旧容量对应位的关系，它只有两种去向：

```text
旧下标
旧下标 + 旧容量
```

这利用了数组容量始终为 2 的幂这一特性：相关位为 `0` 时节点留在原位置，为 `1` 时移动到“原位置 + 旧容量”。因此扩容过程减少了重新计算 hash 的开销，提高了迁移效率。

:::tip[复习要点]
回答扩容时，依次说明“阈值触发 → 新数组容量翻倍 → 节点高低位分流”即可覆盖关键过程。
:::
