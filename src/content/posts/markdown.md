# 一级标题

段落之间用空行分隔。

第二段。_斜体_、**粗体** 和 `等宽字体`。无序列表
长这样：

- 这个
- 那个
- 还有一个

注意——不考虑星号的话——正文内容从 4 个空格的缩进开始。

> 引用块
> 是这样写的。
>
> 只要你愿意，
> 它可以跨越多个段落。

用 3 个连字符表示破折号，2 个连字符表示范围（如"第 12--14 章"）。三个点 ... 会被转换成省略号。
支持 Unicode。☺

## 二级标题

这是一个有序列表：

1. 第一项
2. 第二项
3. 第三项

再看一次正文是如何从 4 个空格缩进开始的。下面是一个代码示例：

    # 让我再重复一遍 ...
    for i in 1 .. 10 { do-something(i) }

正如你猜到的，缩进 4 个空格。顺便说一句，如果你愿意，可以不用缩进，而使用围栏代码块，这样更方便：

```
define foobar() {
    print "Welcome to flavor country!";
}
```

（这样复制粘贴更方便）。你还可以给围栏代码块标记语言，让代码获得语法高亮：

```python
import time
# 快，数到十！
for i in range(10):
    # （但不要*太快*）
    time.sleep(0.5)
    print i
```

### 三级标题

现在是一个嵌套列表：

1. 首先，准备这些食材：

    - 胡萝卜
    - 芹菜
    - 扁豆

2. 烧一壶开水。

3. 把所有东西倒进锅里，然后
    按照这个算法操作：

        找到木勺
        打开锅盖
        搅拌
        盖上锅盖
        把木勺摇摇晃晃地架在锅柄上
        等待 10 分钟
        回到第一步（做完后关火）

    不要碰木勺，否则它会掉下来。

再次注意正文总是对齐在 4 空格缩进处（包括上面续接第 3 条的最后一行）。

这里有一个指向 [某个网站](http://foo.bar) 的链接、一个 [本地文档](local-doc.html)，以及一个指向 [本文档中小节标题](#二级标题) 的链接。这里有一个脚注 [^1]。

[^1]: 脚注内容写在这里。
